# Xilog CNC to Stapling Machine Converter

Java backend tool developed to automate the generation of stapling machine programs from CNC files generated by Xilog.

## Industrial Context:

This project was developed to solve a real manufacturing problem in the furniture industry.
The tool converts drilling coordinates generated by Xilog into stapling positions used during the assembly of acoustic panels.

## Problem

* Acoustic panels required manual programming of stapling positions based on CNC drilling coordinates.

* The process was repetitive and prone to human errors.

## Solution

### The application

* Reads CNC programs exported from Xilog.
* Detects drilling operations.
* Extracts X and Y coordinates.
* Applies configurable offsets
* Generates G-code for an industrial stapling machine.
* Controls the pneumatic stapling system through M-codes.
  
## Technologies

* Java
* File parsing
* G-code generation
* Manufacturing automation
  
## Workflow

Xilog CNC Program ↓ Coordinate Extraction ↓ Offset Calculation ↓ Stapling Machine G-Code Generation

## Results
* Reduced programming time.
* Eliminated manual coordinate conversion.
* Improved process repeatability.
